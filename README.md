# Web Development Practice & Playground

A simple, responsive web page built with HTML and CSS to practice layout design, card components, flexbox positioning, and CSS styling techniques.

## Features
- **Header & Navigation:** Top bar with search functionality and user navigation.
- **Programmes Section:** Dynamic cards showcasing different engineering disciplines.
- **Responsive Layout:** Clean design structured using CSS Flexbox.

## Tech Stack
- HTML5
- CSS3
